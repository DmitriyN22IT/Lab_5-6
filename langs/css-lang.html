Краткое описание

CSS (Cascading Style Sheets) - это язык таблиц стилей, который используется для оформления HTML-страниц. Он определяет внешний вид элементов: цвета, шрифты, размеры, отступы, расположение блоков и многое другое. Благодаря CSS веб-страницы становятся более привлекательными и удобными для восприятия.

CSS отделяет содержание документа от его оформления. Это значит, что структура страницы задаётся HTML, а все визуальные настройки выполняются в CSS. Такой подход делает код более чистым, удобным для поддержки и позволяет быстро менять дизайн сайта.

Современный CSS включает множество возможностей: адаптивную верстку, работу с анимациями, сетками, переменными и медиа-запросами. Эти технологии делают CSS мощным инструментом для создания современных интерфейсов.

Особенности CSS:

  • CSS определяет внешний вид HTML-элементов: цвета, размеры, шрифты и отступы;

  • Стили можно подключать тремя способами: внешним файлом, внутренними стилями или встроенными свойствами;

  • Каскадность означает, что стили могут перекрываться в зависимости от порядка и специфичности.

Пример исходного кода

body {
    font-family: Arial, sans-serif;
    background-color: #f4f4f4;
}

h1 {
    color: #000000;
}

p {
    font-size: 18px;
    color: #A9A9A9;
}
