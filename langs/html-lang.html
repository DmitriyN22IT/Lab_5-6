Краткое описание

HTML (HyperText Markup Language) — это основной язык разметки, который используется для создания структуры веб‑страниц. Он определяет, какие элементы будут присутствовать на странице: заголовки, параграфы, изображения, ссылки, таблицы и формы.

HTML не является языком программирования, потому что он не выполняет вычислений и не содержит логики. HTML описывает структуру и содержание документа. Браузер читает HTML-код и отображает его в виде веб-страницы.

Современный HTML включает поддержку мультимедиа, семантических тегов и взаимодействия с CSS и JavaScript. Благодаря этому язык стал универсальной основой для создания сайтов любой сложности.

Особенности HTML:

  • HTML определяет структуру страницы с помощью специальных тегов;

  • Файлы HTML обычно имеют расширение .html или .htm;

  • Каждый документ начинается с декларации !DOCTYPE html, указывающей на использование HTML5;

  • Браузеры могут корректно воспроизводить HTML-страницы даже при небольших ошибках в коде.

Пример исходного кода

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Пример HTML</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Текст внутри абзаца</p>
</body>
</html>
