Языки программирования курса

Необходимо разработать набор HTML-документов, которые описывают языки программирования, которые упоминаются в данном курсе. Необходимые требования:

• На стартовой странице, index.html, находится краткое описание задачи.

• На странице со списком языков программирования, languages.html, находится несколько списков языков программирования с одинаковым содержимым, но разным оформлением. В каждом из списков должно находится название языка и ссылка к соответствующей странице. Список необходимо оформить следующими способами:

o С помощью группы списков;

o С помощью таблиц;

o С помощью карточек;

• На странице конкретного языка программирования должно присутствовать:

o Название языка программирования, в рамках заголовка h1;

o Ссылка для возвращения к странице списка языка программирования. Ссылка должна быть оформлена:

 Как обыкновенная ссылка с текстом;

 Как кнопка.

o Краткое описание назначения языка, в рамках которого есть h2-заголовок с текстом «Краткое описание», за которым идёт несколько параграфов, p-элементов, с соответствующим содержимым.

o Пример исходного кода, в рамках которого есть h2-заголовок с текстом «Пример исходного кода», за которым идёт форматированный текст внутри элемента code.
